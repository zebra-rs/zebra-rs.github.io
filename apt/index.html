Install (stable channel)

Recommended for most users — published with each tagged release.

# 1. Trust the zebra-rs archive key (scoped to this repo only)
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://zebra.rs/apt/zebra-rs-archive-keyring.asc \
  | sudo gpg --dearmor --yes -o /etc/apt/keyrings/zebra-rs.gpg

# 2. Add the repo for this machine's Ubuntu release
. /etc/os-release
base=https://github.com/zebra-rs/zebra-rs.github.io/releases/download
sudo tee /etc/apt/sources.list.d/zebra-rs.sources >/dev/null <<EOF
Types: deb
URIs: $base/apt-$VERSION_CODENAME
Suites: ./
Signed-By: /etc/apt/keyrings/zebra-rs.gpg
EOF

# 3. Install
sudo apt-get update
sudo apt-get install -y zebra-rs

Install (nightly channel)

Bleeding-edge builds, refreshed every night. Same as above but with the nightly- tag prefix:

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://zebra.rs/apt/zebra-rs-archive-keyring.asc \
  | sudo gpg --dearmor --yes -o /etc/apt/keyrings/zebra-rs.gpg

. /etc/os-release
base=https://github.com/zebra-rs/zebra-rs.github.io/releases/download
sudo tee /etc/apt/sources.list.d/zebra-rs-nightly.sources >/dev/null <<EOF
Types: deb
URIs: $base/nightly-$VERSION_CODENAME
Suites: ./
Signed-By: /etc/apt/keyrings/zebra-rs.gpg
EOF

sudo apt-get update
sudo apt-get install -y zebra-rs

Verify

apt-cache policy zebra-rs     # candidate points at the github.com release URL
systemctl status zebra-rs

Uninstall

sudo apt-get remove -y zebra-rs
sudo rm -f /etc/apt/sources.list.d/zebra-rs.sources \
           /etc/apt/sources.list.d/zebra-rs-nightly.sources \
           /etc/apt/keyrings/zebra-rs.gpg
sudo apt-get update
Not on a supported Ubuntu release? Grab a .deb directly from the GitHub releases page.
